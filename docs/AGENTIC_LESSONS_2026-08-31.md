# Agentic underwriting: the travails, distilled

Source: `evanshields/dream-underwrite` at `main`, plus `design/architecture-v4`, `design/architecture-v5`, and branches `bakeoff/{cc-pure,cc-ha,gpt,ha-pure}-esplanade`. Compiled 2026-08-31 as input to the DREAM v4 PRD. Decisions and hard constraints only; narrative stripped.

Citations are repo-relative. Branch-only files are marked [v4] (design/architecture-v4) or [lane] (bake-off branch).

## 1. Platform lessons

### 1a. Hyperagent

1. **Delegation depth limit is 1, support-confirmed 2026-08-15.** Any MCP correspondence makes the receiving agent a child, and a child cannot spawn children. This one fact forced the whole v3 shape: orchestrator at depth 0 outside the platform, DREAM at depth 1, orchestrator dispatches every specialist. `ORCHESTRATOR.md:11-17`, `ARCHITECTURE-V3.md:3-8`
2. **Scheduled named-agent runs also lose the delegation tool surface** (separate open eng ticket). Rules out a DREAM cron with a crew; it is why her heartbeat is off. `ARCHITECTURE-V3.md:52`, `ARCHITECTURE-V5-HYPERAGENT.md:223`
3. **MCP-created threads lack delegation tools; UI-created and scheduled threads have them.** Same root cause, different symptom, learned the hard way. `SESSION-HANDOFF-2026-08-14.md:57`
4. **Ephemeral subagents share the orchestrator sandbox filesystem and installed packages,** so deal files pass by path at zero token cost. Biggest available token saving, and the thing the depth limit forbids. `ARCHITECTURE-V5-HYPERAGENT.md:224`
5. **A trivial ephemeral subagent costs ~32K tokens of overhead before doing any work;** twelve specialists would burn ~390K per deal on ceremony alone. This measurement, not preference, forced the roster from 13 named agents to 6. `SWARM-SPEC-v2.md:14-16`
6. **Sandbox is Python 3.9.25, `python3` only on PATH.** The receipt writer, whose entire job is to prove a gate ran, uses `Path.write_text(..., newline=...)` which is 3.10+, so it crashes on the runtime that matters. Hits `gate_registry.py:138` and `:178`, plus `spec_identity.py:195`, `generate_manifest.py:551` and five other call sites. CI meanwhile pins 3.12. `ARCHITECTURE-V5-HYPERAGENT.md:122,166`
7. **No cost or token telemetry through any API.** Per-run budget caps in the UI are the only control; runs cannot always be cancelled. Cost per dispatch is unmeasurable, which makes every overhead claim unfalsifiable in both directions. `ARCHITECTURE-V5-HYPERAGENT.md:114,227`; [lane] ha-pure RETRO 2a
8. **Runs that cannot be cancelled make runaway credit burn a financial attack surface, not a bug.** Budget caps are therefore a security control, and the orchestrator cap must be set only from its own measured runs: a cap calibrated on extraction runs trips mid-merge and destroys twelve already-billed spoke runs on a no-checkpoint platform. `SECURITY-PROTOCOL.md:92-94`, `RED-TEAM-2026-08-04.md:16-17`
9. **Some agent spawns return `requiresApproval:true`, which hangs an unattended run on a human click.** Every crew spawn must be pre-approved in autonomy settings and the weekly review checks for hung threads. `SECURITY-PROTOCOL.md:104`, `SWARM-SPEC-v2.md:29`
10. **No per-thread memory isolation and no way to request a memory-blind instance.** Clean-room re-underwriting of a deal the roster has seen is not achievable on the platform. This is why the pure-Hyperagent bake-off lane could not run as designed. `ARCHITECTURE-V5-HYPERAGENT.md:228`; [v4] BAKEOFF-ROUND1-FINDINGS.md F1 corollary
11. **Agent contention is invisible and unmanageable.** In the cc-ha lane DREAM answered turn one in 12 seconds then returned nothing across two queued turns and 30+ minutes because a rival lane drove the same agent; the red-team never returned at all, so the memo shipped with no adversarial review. Roughly 45 of 105 minutes lost to waiting, and the two roles that mattered most produced nothing. No queue depth, no load signal, no reservation. [lane] cc-ha RETRO 2, 3
12. **Attachment URLs are auth-gated, so the courier protocol inlines files into chat, and inlining mutates bytes.** Published URLs are the only byte-exact transport proven. `ARCHITECTURE-V5-HYPERAGENT.md:226`, `ORCHESTRATOR.md:41-44`
13. **Artifacts checkpointed to SaveFile/Tables survive their run and are readable cross-thread by ID,** which largely moots unknown cancellation behavior and demotes Projects. Treat threads as disposable compute. `SWARM-SPEC-v2.md:26`
14. **All sandbox HTTPS runs through the vendor MITM inspection proxy;** no SOC 2 exists for Hyperagent, retention is criteria-based and effectively indefinite. No real credential ever enters a sandbox; skill credentials surface only via `RunWithCredentials`. `SECURITY-PROTOCOL.md:9,104`
15. **`FetchSkillScripts` with no scriptName pulls the full dependency tree; naming one file breaks its imports.** A 52-file skill worked. `SWARM-SPEC-v2.md:31`
16. **DREAM GitHub write path works** (proven by commit `a30c314`); the 403s during the bake-off were the separate, still-unminted read-only token, not a write failure. `ARCHITECTURE-V5-HYPERAGENT.md:229`
17. **Blocking waits are server-capped near 2 minutes and hold the orchestrator billed turn open.** Fan out with `waitSeconds:0` then `WaitForAgentThread`. Namespace every sandbox write as `/agent/workspace/deals/{deal_id}/{specialist}/` or the shared filesystem clobbers same-named files. `SWARM-SPEC-v2.md:25`
18. **Child run states are opaque:** "running" does not distinguish queued from provisioned from stalled, which caused a duplicate red-team dispatch and duplicated review work in the pure-Hyperagent lane. [lane] ha-pure RETRO 3, 5b
19. **Specialists rejected valid parent-thread steering as prompt injection:** on a legitimate parent halt, 4 of 7 specialists refused it, 3 accepted. Cross-thread steering is not structurally distinguishable from document-embedded instructions. [lane] ha-pure RETRO 2d

### 1b. Claude Code

20. **Strongest at deterministic repository work:** branch hygiene, byte-exact registry edits, commit discipline, CI, gate construction, engine study, refusing to invent numbers. Every lane retro converges on it as the controlling production lane. [lane] cc-ha RETRO 6; ha-pure RETRO 6; gpt RETRO 6
21. **Independent re-verification of every specialist return caught three arithmetic errors inside those returns,** including a fabricated "+100 SF discrepancy" that was the analyst own multiplication error and would otherwise have entered the memo as a finding about the input package. Worth more than the transport machinery it rode on. [lane] cc-ha RETRO 6
22. **Sub-agent fragility is the dominant time sink:** ~70 of 280 minutes (40% of the run) lost to failed and stalled subagents. One extractor died on an API session limit after writing 4 of 19 sections; the first red-team attempt died on a 529 having written nothing. [lane] cc-pure RETRO 2, 3
23. **Two agents pointed at one output path with no write protocol clobbered the assembled deliverable;** recovered from git. Self-classified as an orchestration defect, not an agent defect. [lane] cc-pure RETRO 3
24. **`cd` dropped from compound Bash commands more than once,** so verification ran against the wrong repo on the wrong branch and produced a confident wrong report to Evan that the memo was missing from the remote. [lane] cc-pure RETRO 3
25. **Read a stale `origin/*` remote-tracking ref instead of querying the remote,** drew a confident wrong conclusion, corrected only by `git ls-remote`. Noted as walking into the exact trap the supersession gate exists to catch. [lane] cc-pure RETRO 3
26. **`core.autocrlf=true` in a fresh clone would have hard-stopped all 8 text inputs on hash mismatch** and nothing in the brief or repo warned about it. Gate-2 CRLF root cause closed by pinning `autocrlf=false`. [lane] cc-pure RETRO 3, `SESSION-HANDOFF-2026-08-15.md:33-34`
27. **Token spend is at least partially measurable here,** unlike Hyperagent: ~1.1-1.3M tokens across six subagents in the pure lane (tax extractor 118,548; market extractor 113,676; red team part 1 217,165; part 2 181,165; memo-writer unreported). [lane] cc-pure RETRO 2
28. **Grep-not-render is the recurring self-inflicted failure.** A memo was called print-ready on the strength of a grep and a page count; `measure.py` then showed 3 of 11 pages over the letter sheet, page 11 by 876px, PUBLISH BLOCKED. SKILL.md names this exact failure in its opening paragraph. [lane] cc-ha RETRO lead finding
29. **Tooling friction, recorded so it is designed around:** three shell heredoc failures on apostrophes in prose (fixed by switching to the Write tool), and a `json.dump` that rewrote all 372 lines of `THREADS.json` for a four-line addition (fixed by byte-level insert). [lane] cc-ha RETRO 2

32. **The identity prefix leaked into the client-facing document:** the literal text "CODEX:" printed above the logo twice, plus a raw machine token NOT_PRICEABLE_PENDING_COMMITTED_INPUTS in investor-facing prose. Prefixes must be stripped at the memo boundary. [v4] BAKEOFF-ROUND1-FINDINGS.md

### 1d. Cross-harness

37. **Small models fabricate `gh` output.** Standing rule: repo state is verified by the orchestrator directly, always; never act on a sentry repo claims. `SESSION-HANDOFF-2026-08-15.md:79`, `ORCHESTRATOR.md:82-84`
38. **The worst fabrication on record is a self-certification.** LIHTC Manual V1.0 "PRODUCTION READY" certification was written before the files it certified existed; 25 of its 60 checkable claims were false, its Python console transcripts were fabricated, it described 154 classes where 41 exist, and a 43-region sweep found 436 content errors including 36 that would change an investment decision. The V2.1 certification therefore emits only script-measured facts and states in its own header what it does not claim. `manuals/lihtc-v2.1/AAA_READ_FIRST_LIHTC_V2.1.md:14-20`, `manuals/lihtc-v2.1/QA_CERTIFICATION_V2.1.md`
39. **Portability is answered: no vendor owns this workflow.** Three platforms ran a full bond underwrite from identical inputs frozen at `1d44d04` and all three produced defensible work, all landing below the $39.0MM ask, all independently identifying the same structural problem (acquisition fee and issuance costs are uses no loan measured against price can reach). What separated the lanes was not capability; it was honesty about their own uncertainty, which lives in gates and contracts rather than in model choice. [v4] BAKEOFF-ROUND1-FINDINGS.md

## 2. Process lessons

### 2a. What caught real money

40. **Engine-blind memo writer caught a $2.27M overpay on Atlantica.** The exit calc silently used a cheaper expense world (INS $508,836 / reserves $200) than the hold ($880,524 / $250); `exit_solve` accepted no kwargs so the hold assumptions could not be passed through. The defect was self-consistent inside its own wrong world, so every internal check passed. The memo-writer, unable to consult the engine, divided: implied exit income $62,204,081 x 6.50% = $4,043,265 against a year-five income of $3,659,742 growing to at most $3,769,534, exceeding the maximum reachable figure by $273,731. **Had it been able to read `exit_solve` it would have called the function, received a coherent wrong answer, and closed the inquiry. The blindness was load-bearing, not the separation alone.** [v4] ARCHITECTURE-V4-PROPOSAL.md
41. **Two other mechanisms carried that catch and must be specified alongside blindness:** an obligation to publish (it could not ship an exit value without stating the income behind it) and an abstention discipline (it logged a gap and refused to write the sentence rather than asserting "engine bug"). A confident assertion might have been overruled; an abstention with arithmetic attached could not. [v4] ARCHITECTURE-V4-PROPOSAL.md
42. **All three engine defects fixed in Atlantica v5 were found by agents that do not touch the engine** (memo-writer: exit basis; business-plan-strategist: equity-multiple double count and the 1.17x endorsement feedback loop). [v4] ARCHITECTURE-V4-PROPOSAL.md, `deals/atlantica/handoff/CODE-REVIEW-BRIEF.md`
43. **A second legal read overturned the first on the controlling statutory subsection,** worth $1.27M-$2.16M of single-year exposure on Cypress Grove and enough to change whether the exit thesis holds. That required willingness to reject another analyst completed work, which cannot happen inside the context that adopted the earlier conclusion. [v4] ARCHITECTURE-V4-PROPOSAL.md
44. **Atlantica repriced $50.2MM to $47.9MM** off that exit-solver fix, corrected 15% clearing at $47,922,191.62, regression test `test_exit_consistency.py` pinned to it. Provenance chain hash-verified hop by hop: a2c6a15 -> 721c91c -> cb2a62c -> 77cfca2 -> 8891e15 -> 95cb899. `SESSION-HANDOFF-2026-08-15.md:15-23`
45. **Two shadow re-underwrites reproduced the shipped numbers exactly while surfacing six errors nobody had caught.** Cypress Grove: year-one NOI $5,683,569 to the dollar, min amortizing DSCR 1.2000x, residual $60,247,013. Atlantica: all twelve headline figures including $47,922,191.62, IRR 15.0002%, EM 1.9144x, exit $56,808,594, regression output byte-identical. Shadow re-running a shipped deal from committed inputs is the cheapest verification method found. [v4] ARCHITECTURE-V4-PROPOSAL.md
46. **Independent convergence beats any single check.** Lane A red team ran as two halves that never saw each other output, each getting only the frozen spec and a stripped memo. Both named the same two largest defects and both reproduced the clearing price from scratch, landing within $4.10 and $0.14. [v4] BAKEOFF-ROUND1-FINDINGS.md
47. **Specialist division of labour surfaced findings a single context plausibly misses:** a RUBS double count worth $1.64M-$1.94M of phantom value, an upward bias in comp curation, the parcel own history contradicting the 80% reassessment convention (87.5% on the first roll), and Florida 120% AMI ceiling being broader than the federal 80%. Two of three specialists caught real errors in the staged input package. [v4] BAKEOFF-ROUND1-FINDINGS.md
48. **The single best analysis of the bake-off was a netting nobody had done:** the two halves of the 501(c)(3) exemption trade, previously stated separately and never added, net to $60,308/yr against roughly $834,788 of value, and the downside is asymmetric because the revenue giveback is a recorded land use restriction while the tax relief is an annual county determination. They do not fail together. [v4] BAKEOFF-ROUND1-FINDINGS.md
49. **The one wired gate is the one that caught real money** (the $466K reserve error class) and it works by checking cross-file agreement rather than a single value. That is the model the other gates should follow. `ARCHITECTURE-V5-HYPERAGENT.md:19,216`

### 2b. Gates as theater

50. **Ten safety checks are required on a bond deal; two actually run, and neither can fail.** Three lanes reported "all gates passed" and were reporting on checks that had no teeth. `ARCHITECTURE-V5-HYPERAGENT.md:13-14`
51. **Fee bounds always passes on BOND:** `bond_engine.py:2221` calls `assert_fee_bounds(..., routing="BOND")` and `bond_engine.py:597` returns `ok=True` unconditionally for that routing. It is the only call site the bond route runs, including on the 0.05 EFB sentinel. `ARCHITECTURE-V5-HYPERAGENT.md:162`
52. **Unit count compares a number to itself:** `classified_units` from `spec.unit_mix` against `spec.units` with `second_source_count=None`, and `load_spec` has already validated they agree. It can only PASS or WARN. `ARCHITECTURE-V5-HYPERAGENT.md:163`
53. **Three more gates pass when handed nothing, and two literally print `[SKIP] ... THIS IS NOT A PASS` then `return 0`,** with registry `pass_field` set to `exit_zero`, so the receipt records `passed: true`. `gate_supersession.py:161`, same pattern in `gate_memo_sentinels.py`. `ARCHITECTURE-V5-HYPERAGENT.md:171`
54. **`formula_integrity_check({})` passes:** each of five cells does `if <cell> is None: _add(<cell>, "ok")`, so an empty map means nothing was read and `any_bug` is False. `acq_engine.py:906`. `ARCHITECTURE-V5-HYPERAGENT.md:170`
55. **Four of five gate tools have no callers anywhere in the repo.** `gate_registry.py`, `spec_identity.py`, `gate_supersession.py`, `gate_memo_sentinels.py` are invoked by nothing except their own tests, confirmed by repo-wide grep. **Code existence is irrelevant; only invocation counts.** `ARCHITECTURE-V5-HYPERAGENT.md:134`
56. **The receipt system is well designed and never run.** `cmd_check` correctly treats a missing receipt, a stale receipt (input bytes changed since execution), or a FAIL as hard failure. Only `deals/cypress-grove/` has any receipts at all: two files, run by hand. Esplanade, which CI builds a memo for on every push, has zero. `ARCHITECTURE-V5-HYPERAGENT.md:156-158`
57. **CI never collected `tools/ci/tests`:** 128 tests protecting the receipt system, the compat shim, the formula-integrity wrapper and the supersession gate ran only when a human ran them by hand. Same failure mode as the gate tools themselves: real code, real tests, nothing calling them. `ARCHITECTURE-V5-HYPERAGENT.md:95`
58. **The skill mirror had silently diverged in five modules.** `skills/dream-engines/` is the flat mirror `FetchSkillScripts` pulls into DREAM actual sandbox, not `engine/`. `acq_engine.py` was missing the revised reserve ladder and the BOND fee bound; `bridge_teb_engine.py` missing the Ohio exemption-bar fix and both refuse-rather-than-guess loaders; `render_bote_memo.py` still rendered an all-"n/a" memo instead of raising. **Every fix made in `engine/` had never reached the runtime that actually executes.** Now guarded by `tools/ci/sync_skill_mirror.py` plus a drift test. `ARCHITECTURE-V5-HYPERAGENT.md:93-94`
59. **Defaults inherit the last deal.** `bond_engine.py:324` deep-merges `templates/gs-bond-defaults.json` underneath the caller spec; that file header names the Esplanade model as its source and carries `acq_fee_pct: 0.05`. Any omitted field silently inherits a prior deal assumption and returns looking computed. Named by the cc-ha lane as "the single largest correctness trap for any future caller." `ARCHITECTURE-V5-HYPERAGENT.md:164`
60. **`compliance["flags"]` is always empty** (declared `bond_engine.py:1363`, returned `:1374`, never appended to), so posture classification A/B/C/D says nothing about whether the federal Test 1 passed. Callers must read `test1_142d.passed` directly. `ARCHITECTURE-V5-HYPERAGENT.md:165`
61. **The bond route `ltv` gate is an ACQ Excel test** (checks cells B52/B66 for live formulas) and `deal_identity` has no bond implementation at all (it opens a workbook and reads a "Pro Forma" tab; the bond route reads JSON and no workbook exists). The registry required both anyway. `ARCHITECTURE-V5-HYPERAGENT.md:168-169`
62. **`_build_gates()` emits exactly two gate entries and they are defects 1 and 2.** The other eight the registry requires are never invoked by the engine at all. `ARCHITECTURE-V5-HYPERAGENT.md:173`
63. **Three doctrine hard gates refuse only on an explicit `false` and nothing in the repo ever produces one** (`qa.exit_cap_gate`, `qa.ltv_gate`, `qa.rubs_sign` in `fastpath/populator.py`). `RED-TEAM-BACKLOG-2026-08-11.md` item 73
64. **Seven of ten mutations to material underwriting constants survive all 283 tests.** The suite does not defend the doctrine constants. `RED-TEAM-BACKLOG-2026-08-11.md` item 74
65. **There is no gate 6 anywhere in the repo; the numbering jumps.** `ARCHITECTURE-V5-HYPERAGENT.md:132`
66. **The audit verdict that governs everything: eleven of the twelve controls the Cypress run needed already existed as prose, and each one lost at the moment of decision.** "Do not propose another sentence of guidance. Propose an assertion or propose nothing." `deals/cypress-grove/handoff/REVIEW-NOTES-FOR-CLAUDE-CODE.md`
67. **Five numeric defects shipped into intermediate Atlantica versions. Every one was caught by a specialist reading carefully. Zero were caught by a gate.** GPR struck off aspirational market rent $1,985 rather than achievable $1,731 (12% overstatement at the top of the waterfall); equity multiple = distributions/equity + 1 (overstated every multiple by exactly 1.00x); binding constraint modeled as the 1.15x sizing minimum when it is the 1.17x endorsement test on trailing NOI; Live Local haircut computed on two different bases; exit struck on restricted rents AND full taxes. `deals/atlantica/handoff/CODE-REVIEW-BRIEF.md`

70. **A two-sided fill gate is needed, not just an overflow gate:** a page rendering 47% full passes a fit check while still being wrong. `deals/cypress-grove/handoff/REVIEW-NOTES-FOR-CLAUDE-CODE.md` audit rank 3

76. **Verdict vocabulary was itself fail-open:** a blocked gate produced a verdict labeled PASS (renamed BLOCKED, commit 9fa7789) and the bridge engine walk-away verdict was labeled PASS (renamed DECLINE, commit 32eb629). `ARCHITECTURE-V5-HYPERAGENT.md:83`

### 2d. Supersession and spec identity

79. **Atlantica repriced result carries the same `spec_id` and `spec_version` as the superseded, void $50.2MM run.** Only the engine commit distinguishes them. In the memo-writer own words, a memo assembled against the wrong cached spec would fail no version check. Fix: identity is the SHA-256 of the canonicalized frozen spec plus input-manifest hash, engine commit, engine config hash, route and schema version; memo assembly binds to the digest. [v4] ARCHITECTURE-V4-PROPOSAL.md gate proposal 3
80. **Superseded artifacts stay authoritative-looking.** Cypress carried a stale `final.py` at $91MM beside the authoritative `full.py` at $76MM, and `property-tax-analysis.json` is still committed asserting the exemption dies on transfer with no staleness signal. Fix: every artifact contract carries `status`, `superseded_by`, `effective_at`, `reason`, `governing_input_manifest`; exactly one current artifact per contract; CI fails on zero or on more than one; stale files stay readable and cannot enter the build graph. [v4] ARCHITECTURE-V4-PROPOSAL.md gate proposal 4
81. **A value regressed backwards through supersession:** the superseded `final.py` had the correct $250 reserve and the live files carried $300. The `vintage_reserve_floor` gate is a FLOOR, so $300 sits above it and passes. What actually fires is the cross-file consistency check added in PR #12, because the deal carried $250 in two engine files and $300 in two others and nothing compared them. Cumulative impact ~$466,580. [v4] ARCHITECTURE-V4-PROPOSAL.md, [v4] DECISIONS-FOR-EVAN.md decision 2
82. **"Two valuation figures carried forward from a superseded model run that reconciled to nothing in the current spec. That is not arithmetic and no footing assertion will ever catch it."** Fix is run identity: the solver stamps `run_id` on every figure and moves prior runs to `superseded/` on write, so two live runs cannot coexist and a memo accepts exactly one. Still unbuilt. `deals/cypress-grove/handoff/REVIEW-NOTES-FOR-CLAUDE-CODE.md` defect 5, audit rank 5
83. **Stale manifests masquerade as hash drift.** Four NO_MATCH_FOUND entries in `RECONCILIATION-MANIFEST.json` were the manifest written once at dd2af43 while the underlying files kept being revised through the repricing sequence. Same defect class as supersession, not a transport problem. `DIAGNOSTIC-HASH-DRIFT.md:33`
84. **Memo sentinels are lint by embarrassment.** `"lead": "__MEMO_WRITER_REQUIRED__"` appears in exactly three files, all in one deal directory, and no assembler, test or CI check asserts on it. It works only because the token looks obviously wrong to a human. The eleven barred numeric literals from the void $50.2MM state live in a briefing document, not in code. DREAM: "Automate both. No legitimate reason exists not to." Her explanation for why they were not: governance evolved inside deal briefs faster than the packaged assembler and CI. [v4] ARCHITECTURE-V4-PROPOSAL.md gate proposal 1

### 2e. Transport and the courier tax

85. **On Atlantica the memo-writer recomputed SHA-256 on all four delivered content files, matched none of them, and proceeded per the delivery instruction.** The rent-comp analyst separately hit a SHA-1 mismatch on a rebuild-spec blob. Four of four is a systemic boundary defect, not random corruption, and proceeding after a mismatch was wrong. `DIAGNOSTIC-HASH-DRIFT.md:5`, [v4] V3-TO-V4-MIGRATION.md step 1b
86. **The repo side is clean: 49 of 49 declared digests matched raw bytes at their source commit** (44 control-group entries across five manifests, 5 suspect-group THREADS.json prefixes), with zero requiring any of thirteen tested canonicalizations. The absence of any CRLF/BOM/NFC noise is what narrows the defect to the chat-inlining step rather than git. Confidence: moderate-to-high on mechanism, low on any specific transform, because the mid-transport bytes were never committed anywhere readable (classified SOURCE_UNAVAILABLE rather than guessed). `DIAGNOSTIC-HASH-DRIFT.md:62-66`
