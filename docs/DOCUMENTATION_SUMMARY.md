### 2. User Flows Documentation ✓
**Location:** `/docs/flows.md`  
**Audience:** Product managers, UX designers, analysts  
**Purpose:** Detailed walkthroughs of 8 core user journeys

**Flows Documented:**
1. **New User Onboarding** (10 min)
   - Sign up → Investment criteria wizard → First deal → Analysis review
   
2. **Quick Deal Screening (BOE)** (2 min)
   - Receive teaser → Upload → BOE results → Pass/proceed decision
   
3. **Full Deal Underwriting** (7 min)
   - Trigger full UW → Review assumptions → Approve pro forma → Generate IC memo
   
4. **Investment Committee Presentation** (30-60 min)
   - Prepare materials → Present with live pro forma → Q&A → Vote → Update status
   
5. **Pipeline Management**
   - Kanban view → Filter/sort → Update stages → Assign tasks → Review activity
   
6. **Pro Forma Sensitivity Analysis**
   - Base case → What-if analysis → Scenario modeling → Comparison
   
7. **Team Collaboration**
   - Team permissions → Real-time editing → Comments & discussions
   
8. **Custom Investment Criteria Setup**
   - Configure hard stops → Target ranges → Soft preferences → Test against historical deals

**Length:** ~1,600 lines  
**Success Metrics Defined:** 24 specific targets across all flows

### 3. CRE Underwriting Concepts Guide ✓
**Location:** `/docs/cre-underwriting-concepts.md`  
**Audience:** Analysts, investors, principals  
**Purpose:** Educational guide to multifamily investment metrics

**Topics Covered:**

1. **Introduction**
   - What makes good underwriting
   - Transparent, defensible, conservative principles

2. **Property Fundamentals**
   - Class A/B/C definitions
   - Unit mix analysis
   - Occupancy metrics

3. **Financial Metrics**
   - Revenue (GPR, EGI, other income)
   - Operating expenses (typical ranges per unit)
   - Net Operating Income (NOI)

4. **Return Calculations**
   - Cap Rate (going-in, stabilized, exit)
   - Internal Rate of Return (IRR)
   - Equity Multiple (EM)
   - Cash-on-Cash (CoC)
   - Debt Service Coverage Ratio (DSCR)
   - Net Investor IRR

5. **Risk Assessment**
   - Risk-adjusted return hurdles
   - Red flags vs. risk factors
   - Sensitivity analysis

6. **Market Analysis**
   - Market tier classification (Gateway/Secondary/Tertiary)
   - Key market metrics
   - Employment, demographics, regulatory environment

7. **Valuation Methods**
   - Income approach (primary for multifamily)
   - Sales comparison approach
   - Cost approach

8. **Financing Structures**
   - Agency debt (Fannie/Freddie)
   - Bridge debt
   - Bank debt
   - Refinancing (90/90 rule)
   - Mezzanine & preferred equity

9. **Value-Add Strategies**
   - Revenue enhancement (rent to market, renovations, amenities, other income)
   - Expense reduction (operational efficiencies, utilities, tax appeals)
   - Business plan example (classic value-add)

10. **Exit Strategies**
    - Exit cap triangulation (3-method approach)
    - Hold period considerations

11. **Due Diligence**
    - Financial, physical, environmental, legal

12. **Common Pitfalls**
    - 10 mistakes analysts make and how to avoid them

**Length:** ~1,400 lines  
**Real-World Examples:** Throughout with actual numbers
