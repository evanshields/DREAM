# Case Studies (NOT loaded by default)

This folder holds extended worked examples from prior deals. Per the leanness discipline encoded in [shieldstone-skill-improve/SKILL.md](../../../shieldstone-skill-improve/SKILL.md) §Leanness:

- The runtime skill (SKILL.md + references/01-17) keeps **at most 2 worked examples per rule** inline
- When a 3rd example would be added, the oldest gets retired here
- These files are read ONLY when explicitly cited from a rule (`→ see case-studies/<deal>.md`), never loaded into a normal Phase 1-12 flow
- They exist as audit trail and onboarding material, not as runtime context

## File naming

`<deal-slug>-<YYYY-MM-DD>.md`, e.g., `esplanade-orlando-2026-05-15.md`.

## What goes in a case-study file

- Deal context (asset, market, structure)
- Specific decisions made during underwriting with reasoning
- Template bugs caught with cell-by-cell detail
- Pushback moments and how they reshaped the underwrite
- Quoted numbers and where they came from

## What does NOT go here

- Abstract rules (those live in references/01-17)
- Universal patterns (those live in SKILL.md Universal Rules)
- Phase-specific procedures (those live in SKILL.md phase descriptions)
